## SyncShare P2P File Sharer - Backend

Project created while MCA Semester 2.

**Creating Using**

MongoDB
Express
Node.js
React - Frontend

Backend deployed on `Render`

## Installtion Step

Clone the Repo
```sh
git clone <git-url>
npm install
```

Create and config .env file using .env.sample:
```sh
PORT=5000
```

Run the app
```sh
npm run start
```
